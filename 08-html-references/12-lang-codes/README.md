# HTML Lang Codes

El atributo global `lang` especifica el idioma del contenido. Se usa un código de idioma, como `es` para español o `en` para inglés.

```html
<html lang="es">
  <body>
    <p>Este párrafo está en español.</p>
    <p lang="en">This sentence is in English.</p>
  </body>
</html>
```

Declarar el idioma ayuda a tecnologías de asistencia, correctores y navegadores a procesar o pronunciar el texto correctamente. Indica el idioma general en `<html>` y cambia `lang` en fragmentos que estén escritos en otra lengua.
