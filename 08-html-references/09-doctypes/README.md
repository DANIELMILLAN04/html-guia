# HTML Doctypes

El doctype es la declaración inicial que indica al navegador que interprete el documento en modo estándar. En HTML moderno se escribe:

```html
<!DOCTYPE html>
<html lang="es">
  ...
</html>
```

No es una etiqueta que envuelva contenido. Si se omite, algunos navegadores pueden adoptar un modo de compatibilidad antiguo, lo que altera la interpretación del diseño. Colócalo al principio del archivo.
