# Keyboard Shortcuts

Los atajos de teclado ejecutan acciones mediante combinaciones de teclas. Dependen del sistema operativo y de la aplicación: un atajo de W3Schools puede no coincidir con el de Visual Studio Code o el navegador.

Algunos atajos comunes en Windows son:

- `Ctrl + F`: buscar en la página o documento.
- `Ctrl + Z`: deshacer en muchos editores.
- `Ctrl + S`: guardar en editores de archivos.

En muchas aplicaciones de macOS se usa `⌘ Command` en lugar de `Ctrl`. Consulta la ayuda del editor o navegador concreto para conocer su lista actual. Estos atajos no son parte del lenguaje HTML.
