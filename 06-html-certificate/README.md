# 6. HTML Certificate

Este apartado trata sobre el certificado de HTML que ofrece W3Schools; **el certificado no forma parte del lenguaje HTML**. Es una evaluación o credencial de una plataforma educativa.

Antes de apuntarte, consulta la página oficial para confirmar el contenido, el formato del examen, el coste y las condiciones vigentes. Completar un certificado puede demostrar que has estudiado ciertos contenidos, pero no equivale automáticamente a una titulación oficial ni garantiza experiencia profesional.

Para prepararte con este repositorio, estudia los fundamentos, completa los ejemplos y asegúrate de poder explicar qué hace cada etiqueta. El código de ejemplo está en las carpetas [`01-html-tutorial`](../01-html-tutorial/README.md), [`02-html-forms`](../02-html-forms/README.md) y [`07-html-examples`](../07-html-examples/README.md).
