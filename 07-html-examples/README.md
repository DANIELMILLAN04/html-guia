# 7. HTML Examples

Esta sección reúne ejemplos y actividades para practicar. El archivo [`sitio.html`](sitio.html) combina etiquetas de las secciones anteriores en una página sencilla que puedes abrir directamente en el navegador.

## Cómo estudiarlo

1. Abre `sitio.html` y observa la página.
2. Lee el código e identifica `header`, `nav`, `main`, `section` y `footer`.
3. Cambia los textos, añade otra sección o crea una lista.
4. Añade un formulario a partir de [`02-html-forms`](../02-html-forms/README.md).
5. Prueba la navegación y revisa que el idioma y los textos alternativos sean adecuados.

Los quizzes, ejercicios, retos, temarios y materiales de entrevista de W3Schools son recursos de práctica de esa plataforma. Este repositorio proporciona ejemplos locales, pero no ejecuta ni reproduce sus cuestionarios.
