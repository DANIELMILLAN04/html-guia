# Guía práctica de HTML

Repositorio de estudio en español basado en los apartados del tutorial de HTML de W3Schools. Incluye explicaciones, ejemplos que puedes abrir en un navegador y una referencia desglosada.

## Cómo probar los ejemplos

1. Descarga o clona el repositorio.
2. Abre los archivos `.html` en un navegador o en un editor como Visual Studio Code.
3. Para ejemplos con varios archivos, mantén juntos los archivos indicados en su README.
4. Los ejemplos que usan APIs del navegador pueden necesitar permisos, HTTPS o un servidor local.

HTML estructura el contenido; CSS controla su presentación y JavaScript añade comportamiento. Los formularios y ejemplos de APIs de esta guía son didácticos: una aplicación real también debe validar y proteger los datos en el servidor.
